# Распределённое назначение задач в гетерогенном рое БПЛА

Предварительная статья для ПЗ-3 по дисциплине «Научное письмо».

**Автор:** Басанский Денис Васильевич, БПМ-23-РК-1, НИТУ «МИСИС».

**Email:** m2305618@edu.misis.ru.

**Тема:** распределённое назначение задач при ограниченной и переключающейся связи.

## Материалы

- [Исходник статьи](article.tex).
- PDF: артефакт `article.pdf` последнего успешного запуска [GitHub Actions](https://github.com/Bigilittle/misis-article-latex/actions/workflows/build.yml).

Исследуется событийный вариант частичного перепланирования CBBA. После появления или восстановления линии связи её концы могут пересмотреть небольшой хвост своих пакетов. Обязательное разрешение конфликтов затрагивает все зависимые назначения. Возможности БПЛА задают жёсткую допустимость выполнения задач.
